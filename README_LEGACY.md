# LEPAS Jogja Website

Website Next.js untuk informasi dan konsultasi penjualan LEPAS di Yogyakarta.

## Jalankan di Windows / PowerShell

```powershell
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Production

```powershell
npm run build
npm start
```

## Kontak utama

- LEPAS L8 PHEV
- LEPAS E4 BEV

## Branding

Palet situs: deep forest, ivory, dan champagne. Tagline: **Drive Your Elegance**.

Ilustrasi kendaraan di `public/images/` adalah SVG stylized placeholder, bukan foto produk resmi. Ganti dengan aset resmi LEPAS jika hak penggunaan aset sudah tersedia.
