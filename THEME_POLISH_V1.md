# Theme Polish V1 — 1.9.0

Fokus: memoles keseluruhan tampilan agar terasa lebih premium, modern, dan konsisten tanpa mengubah struktur konten/SEO Phase 3.

Perubahan utama:
- Global site shell dengan layered radial gradient + technical grid sangat halus.
- Header menjadi frosted glass premium dengan highlight dan depth yang lebih rapi.
- CTA merah menggunakan gradient/shadow yang lebih hidup namun tetap Isuzu-centric.
- Footer dibuat lebih dimensional dengan graphite gradient, red ambient glow, dan detail lingkar teknikal.
- Homepage section background dirapikan agar transisi light/dark lebih menarik.
- Business Solutions mempertahankan glass pill dan mendapat card lift/depth yang lebih premium.
- Why Isuzu mendapat ambient red lighting pada dark section.
- Spotlight/Fleet section diberi pencahayaan/gradient halus agar tidak flat.
- Wrapper halaman internal memakai site-shell yang sama supaya tema konsisten di seluruh website.

Catatan validasi:
- Source patch dibuat dari SEO Phase 3 Glass.
- npm install/npm ci pada environment kerja timeout, sehingga typecheck/build penuh tidak dapat divalidasi di environment ini.
- Jalankan `npm ci`, `npm run typecheck`, dan `npm run build` di project lokal sebelum push.
