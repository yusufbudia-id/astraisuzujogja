PATCH JOURNAL ONE ROW — SINGLE FILE

Hanya satu file yang perlu diganti:
HomeClient.tsx

Cara pasang:
1. Buka project kamu.
2. Masuk ke folder: src/app/
3. Pastikan file page.tsx masih ada.
4. Copy HomeClient.tsx dari ZIP ini ke folder src/app/
5. Pilih Replace/Overwrite untuk HomeClient.tsx saja.
6. JANGAN hapus atau replace seluruh folder src/app.
7. Hapus folder .next bila ada.
8. Jalankan npm run dev.

Target akhir harus menjadi:
src/app/page.tsx
src/app/HomeClient.tsx

Jika HomeClient.tsx berada di src/app/src/app/HomeClient.tsx atau folder lain, Next.js tidak akan menemukannya.
